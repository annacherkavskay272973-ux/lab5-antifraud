# Лабораторная №5 — Google Colab

## Что внутри
- `Лаба_5_Антифрод_Colab.ipynb` — готовый ноутбук со всем кодом.
- `README.md` — инструкция.
- `requirements-colab.txt` — основные внешние зависимости (Colab установит их в первой ячейке).

## Запуск без установки программ на Mac
1. Открой https://colab.research.google.com/
2. Нажми **Файл → Загрузить блокнот (Upload notebook)** и выбери `Лаба_5_Антифрод_Colab.ipynb`.
3. Выбери **Среда выполнения → Выполнить все (Runtime → Run all)**.
4. В ячейке загрузки файла выбери на Mac **`creditcard.csv.zip`** из лабораторной №5.
5. После обучения откроются таблицы и два графика; в конце браузер предложит сохранить **`lab5_results.zip`**.

В Colab используй тип среды выполнения **CPU**. Не требуется установка Homebrew или libomp. Для выполнения Colab нужен интернет.

## Обязательные требования из Moodle
- `train_test_split(test_size=0.3, stratify=y)`: тест 30%, доли классов сохранены;
- Bagging, Random Forest, LightGBM;
- подбор параметров по Macro F1 на валидации;
- CatBoost;
- матрица ошибок лучшего алгоритма;
- код в Git-репозитории (публикуется вручную).

## Важно
Исходный `creditcard.csv.zip` не вложен в этот архив, потому что нужен именно твой файл датасета. Он у тебя уже есть на компьютере. Загрузи его в соответствующей ячейке Colab. ZIP распаковывать не нужно.

После обучения сохраняется `RESULTS_REPORT.md`, `validation_tuning.csv`, `model_comparison.csv`, `macro_f1_comparison.png`, `confusion_best.png`.

## Как запустить отдельные ячейки
Слева у ячейки кнопка `▶`. Можно запускать по очереди сверху вниз, либо использовать **Среда выполнения → Выполнить все**. При перезапуске среды файлы и переменные Colab могут удалиться — тогда снова загрузи ZIP.
